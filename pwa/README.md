# تطبيق الركائز البشرية (PWA)

هذا تطبيق مستقل بواجهة موبايل وتبويبات سفلية، مع بيانات الموقع وخدماته. يبقى الموقع الأصلي كما هو؛ تعديلات التطبيق تكون داخل `pwa/`.

## نشره كمشروع Vercel منفصل

1. في Vercel أنشئي مشروعًا جديدًا من مستودع GitHub نفسه.
2. من إعدادات المشروع اختاري **Root Directory: `pwa`**. اتركي إعدادات البناء الافتراضية؛ يعتمد التطبيق على صفحات ثابتة وVercel Functions.
3. أضيفي متغيرات البيئة التالية إلى مشروع PWA:
   - `SUPABASE_URL`
   - `SUPABASE_PUBLISHABLE_KEY` — المفتاح العام الذي يبدأ بـ `sb_publishable_`.
   - `SUPABASE_SECRET_KEY` — المفتاح السري الذي يبدأ بـ `sb_secret_`، للخادم فقط.
   - `VAPID_PUBLIC_KEY`
   - `VAPID_PRIVATE_KEY` — سرّي للخادم فقط.
   - `VAPID_SUBJECT` — مثل `mailto:info@alrkayzb2.com`.
   - `PWA_PUSH_WEBHOOK_SECRET` — سرّ مشترك بين Vercel وSupabase لتوثيق إشعار نشر عاملة جديدة.
   - `PWA_ALLOWED_ORIGIN` — رابط التطبيق الكامل، مثل `https://app.example.com`.
   - `GROQ_API_KEY` و`GROQ_MODEL` للشات، إذا أردتِ نفس مساعد الموقع.
   - إعدادات Google Places الاختيارية إذا أردتِ التقييمات الحية.
4. شغّلي مرة واحدة ملف `supabase/push-subscriptions.sql` من SQL Editor في مشروع Supabase المرتبط بالموقع.
5. أنشئي مفاتيح VAPID محليًا من مجلد `pwa/`:

   ```powershell
   npm install
   npm run generate-vapid
   ```

   تُحفظ المفاتيح في `pwa/.env.local` المستثنى من Git. انسخي القيم إلى متغيرات Vercel؛ لا ترفعي الملف إلى GitHub.

6. بعد نشر التطبيق، خزّني رابط PWA والسر نفسه في Supabase Vault عبر SQL Editor، مع استبدال الرابط والسر بقيمك:

   ```sql
   select vault.create_secret('https://YOUR-PWA.vercel.app', 'pwa_push_webhook_url');
   select vault.create_secret('YOUR_PWA_PUSH_WEBHOOK_SECRET', 'pwa_push_webhook_secret');
   ```

   قيمة السر هي `PWA_PUSH_WEBHOOK_SECRET` من `pwa/.env.local`. بعدها شغّلي ملف SQL المذكور في الخطوة السابقة لتفعيل اشتراكات التنبيه ومحفّز العاملات.

## التثبيت والتنبيهات

- يفتح رابط Vercel على HTTPS، ثم يضغط العميل **تثبيت التطبيق** أو يختار «إضافة إلى الشاشة الرئيسية» من قائمة المتصفح.
- على iPhone/iPad، افتحي الرابط في Safari ثم المشاركة ← **إضافة إلى الشاشة الرئيسية**. بعد فتح النسخة المثبتة يمكن تفعيل التنبيهات.
- يختار العميل تنبيهات العاملات أو التأجير أو كليهما من تبويب «حسابي».
- عند نشر عاملة متاحة جديدة من لوحة العاملات، يرسل Supabase تنبيهًا تلقائيًا لمشتركي فئة العاملات.
- يرسل مدير النظام النشط تحديثات التأجير من `/notifications.html` للمشتركين الذين اختاروا التأجير. يتحقق الخادم من جلسة Supabase ودور `super_admin` قبل الإرسال.
- موافقة العميل على التنبيهات اختيارية، ويمكن إيقافها من زر التطبيق أو إعدادات المتصفح.

## حدود العمل دون اتصال

تُخزّن واجهة التطبيق وملفاتها الأساسية بعد أول فتح. إرسال الطلبات والشكاوى، تحديث العاملات، والتنبيهات تحتاج اتصالًا بالإنترنت؛ وعند انقطاعه تظهر صفحة إعادة المحاولة.
