الأدمنز

الأدمن يرفع السيرة الذاتية ويراجع المسودة التي رفعها، ويتابع الطلبات والشكاوى. لا يمكنه تعديل المحتوى المنشور أو إدارة الموظفين.

من Supabase: Authentication → Users → Add user. أنشئي حساب الموظف، ثم انسخي User UID إلى النموذج. لا تفعّلي التسجيل العام للموقع.

إضافة أدمن

أنشئي حسابه في Supabase Auth أولًا، ثم اربطيه هنا بالـ User UID.

صلاحيات الأدمن

صلاحيات ثابتة ومحدودة لحماية إعدادات الموقع.

  • رفع PDF ومراجعة بيانات وصورة مسودة الملف التي أضافها بنفسه، دون نشرها أو تعديل ملفات الآخرين.
  • متابعة طلبات العملاء وتحديث حالة التواصل.
  • استلام الشكاوى وتسجيل خطوات حلها.
  • لا يملك صلاحية تعديل محتوى الموقع أو إضافة موظفين.
