# تحليل السير الذاتية في إدارة الموقع

يستخدم قسم «إدارة الموقع ← السير الذاتية» محرك OCR الموجود في `python-service`، ويرسل السيستم طلب التحليل عبر `/api/worker-extraction`. يحافظ الخادم على سر خدمة التحليل، ويتحقق من جلسة المستخدم وصلاحية `rental.website.write` ويطلب رابط تنزيل مؤقتاً للملف من التخزين الخاص. تُحفظ السيرة كمسودة قبل التحليل، وتُراجع الحقول والصورة قبل الحفظ؛ لا يُنشر الملف تلقائياً.

## الإعداد المحلي

- يتطلب Python مع حزم `python-service/requirements.txt` وTesseract مع لغتَي `ara` و`eng`.
- في ملف `.env.local` الخاص بالسيستم، اضبط `SUPABASE_URL` ومفتاحه العام، و`CV_EXTRACTION_URL=http://127.0.0.1:8767` و`CV_EXTRACTION_SECRET` بقيمة عشوائية سرية طويلة. لا تضع السر في Git أو المتصفح.
- شغّل خدمة Python من مجلد `python-service` مع تمرير `SUPABASE_URL` و`CV_EXTRACTION_SECRET` نفسيهما في بيئة العملية، باستخدام `py -m uvicorn app:app --host 127.0.0.1 --port 8767`.
- شغّل `npm run build` ثم `npm run dev` من مجلد السيستم. في ويندوز يمكن استخدام مسار npm CLI المذكور في README الرئيسي.
- تأكد من `/health` على منفذ الخدمة ومن وجود لغتَي OCR، ثم جرّب PDF تجريبياً من واجهة السيستم. عند فشل التحليل تبقى المسودة والملف، ويمكن إعادة المحاولة أو تعديل البطاقة.

## النشر

الخدمة وواجهة الـ API هنا مهيأتان للتشغيل المحلي. النشر يتطلب خدمة OCR موثوقة مستقلة مع HTTPS وسر مشترك، وربط مسار `/api/worker-extraction` بخادم يطبق `scripts/api/worker-extraction.mjs`، وإعداد متغيرات البيئة على الخادم. الاستضافة الثابتة وحدها لا تشغّل Python أو مسار الـ API. لا تنقل مفاتيح سرية أو بيانات السير إلى المتصفح.
