# استيراد وتصدير عقود الاستقدام

قالبا XLSX وCSV يطابقان ترتيب الأعمدة الـ19 في ورقة `Sheet9` من مصنف الاستقدام المرجعي. تُقرأ ورقة العقود المطابقة فقط، وتُترك أوراق البلدان والتذاكر كما هي.

1. افتح إحدى صفحات قسم «إدارة الاستقدام» ثم «استيراد / تصدير ملفات». اختر XLSX أو CSV لتصدير نتائج الصفحة الحالية أو لتنزيل قالب فارغ.
2. عند استخدام Excel، اختر XLSX للحفاظ على أرقام العقود والهويات والصادر والجواز كنص. تُقبل خلايا التاريخ في Excel، واستخدم `YYYY-MM-DD` للتواريخ المكتوبة كنص لتجنب التباس اليوم والشهر. عند استخدام CSV احفظه بترميز UTF-8. المتبقي وحالة الضمان يحسبهما النظام.
3. أبقِ رقم العقد الأصلي عند تعديل عقد موجود. الاستيراد يطابق رقم العقد داخل الشركة ويعرض نتيجة كل صف قبل الحفظ. استخدم تصديرًا حديثًا حتى لا تعيد قيمًا قديمة.
4. إذا ظهرت أخطاء، صحّح الصفوف ثم أعد المعاينة، أو فعّل «استيراد الصفوف الصالحة فقط» لتخطي الصفوف غير الصالحة وكل النسخ المكررة داخل الملف. يُحفظ الاختيار كدفعة واحدة. إذا غيّر مستخدم آخر أحد العقود بين المعاينة والحفظ، تُرفض الدفعة.

الأعمدة التي تخص الأرشفة والملاحظات الداخلية تظل محفوظة عند تحديث العقود بالقالب المرجعي. «مدة الاستقدام» تظل ضمن القالب، حتى بعد إخفائها من نموذج العقد. تُقرأ نتائج الصيغ المحفوظة في ملف Excel دون تشغيل الصيغ. لم تُنسخ سجلات المصنف المرجعي أو تُرفق بالمشروع.
